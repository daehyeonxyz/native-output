# 발표 자료 층 — 슬라이드 텍스트와 대본

슬라이드에 인쇄되는 글과 그것을 말로 푸는 대본에 공용 층 위로 겹쳐 적용한다. 두 층은 결이 다르므로 한 벌로 쓰지 않는다.

## 제목 층

- 슬라이드 제목은 가장 짧은 건조 명사구다. 주장형 문장으로 쓰지 않는다.
- "목차", "동작 원리", "활용법" 같은 압축 한자어를 그대로 쓴다. "오늘 다루는 여섯 가지" 가 아니라 "목차" 이고, "AI가 답변을 생성하는 방식" 이 아니라 "AI의 동작 원리" 다.
- **산문 담화 규칙을 제목에 이식하면 틀린다.** `discourse.md` 의 "소제목은 그 절의 주장을 그대로 말한다" 는 산문의 규칙이고, 슬라이드 제목의 기준은 보고서 결의 압축 명사구다.
- 제목과 개조식 항목에 마침표를 찍지 않는다.
- 영문 용어를 다룰 때는 "영문 용어 : 한국어 풀이" 콜론 꼴이 쓸 만하다.

## 본문 층

- 개조식(명사 종결)으로 한 줄에 한 개념을 담는다. 완결 서술 문단을 슬라이드에 길게 얹지 않는다.
- 페이지당 주장 하나다. 한 장에 두 주장이 들어가면 장을 가른다.
- 강조는 볼드로, 색은 구조 구분으로 역할을 가른다. 볼드는 핵심 명사구와 대비의 축에만 걸고, 문장 전체를 강조하지 않으며, 본문에 여러 색을 뿌리지 않는다.
- 근거와 출처는 감추지 않고 본문 옆에 그대로 노출한다.

## 구성

- 기본 골격은 문제 → 접근 → 방법 → 결과 → 논의 → 다음 질문이다.
- 논증 단위(질문, 가설, 실험)는 번호로 끊어 따라가기 쉽게 만든다.
- 한계를 짚고 나서 결론으로 간다. 남의 작업을 다룰 때도 약점을 먼저 인정하는 순서를 지킨다.
- 마지막에 소회나 토론 주제를 두어 다룬 내용을 자기 문제의식으로 되당긴다.
- 개념 설명에 비유를 쓸 때는 한 덱 안에서 하나의 비유를 끝까지 밀고 간다. 여러 비유를 섞으면 뜻 전달이 실패한다.

## 대본 층

- 대본은 슬라이드와 다른 결이다. 완결 구어체로 쓰고 청중을 직접 부른다.
- 청중에게 직접 말하는 자리(도입, 전환, 대본)는 경어체다. 슬라이드 텍스트 층의 명사 종결을 대본에 옮기지 않는다.
- 질문으로 끌고 예시로 받친다. 개념어를 던지기 전에 정의를 먼저 푼다.
- 일상 예시로 진입해 개념으로 올라간다.
