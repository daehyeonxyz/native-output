# standards

에이전트가 한국어를 쓸 때 따르는 기준 문서 모음이다. 사람이 읽을 수 있는 평문이고, 팀에 맞게 고쳐 쓴다.

## 적용 순서

레이어는 겹쳐 적용한다. 아래 순서대로 전부 적용하고, 충돌하면 더 구체적인 레이어를 우선한다.

| 순서 | 파일 | 정하는 것 |
|---|---|---|
| 1 | `judgment.md` | 무엇을 쓸지. 목적, 독자, 내용 판단 |
| 2 | `korean.md` | 문장. 번역투 교정 |
| 3 | `discourse.md` | 글의 구성. 시작, 전개, 끝, 제목 |
| 4 | `style.md` | 표현과 표기. 말투, 상투 표현 |
| 5 | `genres.md` + `genres/` | 글 종류 판정과 종류별 기준 7종 |

- 별도 기준을 따르는 글에는 전용 레이어를 추가로 적용한다.
  - `reference.md`: 사내 참조 문서, 매뉴얼, FAQ, 안내서.
  - `dev-prose.md`: 개발 문서, 코드 주석, 결정 기록, 명세.
  - `ui-copy.md`: 앱과 웹의 화면 문구.
  - `slides.md`: 발표 자료.

- `banned-words.json`: 금지 표현 목록이다.
  - 잘 쓴 글의 실측에서 모든 글 종류 0회로 확인된 표현이고, 훅이 Write 와 Edit 마다 대조한다.

## 레이어 사이의 우선순위

- 소제목: `discourse.md` 는 소제목이 절의 주장을 요약해야 한다고 정한다. 산문의 규칙이다.
  - 슬라이드 제목은 `slides.md` 의 명사구 규칙을 우선한다.
  - 화면 라벨은 `ui-copy.md` 의 명칭 규칙을 우선한다.
- 비유: `style.md` 는 비유를 금지하지만, 발표 자료의 개념 설명은 `slides.md` 에 따라 예외다.
- 상투 표현: `style.md` 의 목록은 글 종류가 최종 판정한다. 판정표는 `genres.md` 에 있다.

## 수치

- `genres/` 의 수치(문장 길이 중앙값, 쉼표, 말투 분포)는 잘 쓴 글을 측정한 값이다.
- 목표값으로 삼되 문장마다 재지 않는다. 중앙값이 5자 안팎으로 들면 맞은 것이다.
- 두 번 조정해도 안 맞으면 더 고치지 않고 수치를 그대로 보고한다.
- 수치를 바꿀 때는 잘 썼다고 합의된 글 몇 편을 실제로 측정해서 바꾼다. 인상으로 바꾸지 않는다.

## 고쳐 쓰는 법

- `dev-prose.md` 의 교정 사전: 회사 용어집과 제품명 표기를 표에 추가한다.
- `genres.md` 의 판정표: 우리 분야에서 정상인 표현을 "정상인 글 종류" 열에 올린다.
- `banned-words.json`: 잘못 걸릴 가능성이 낮은 형태(명사, 완결형 문구)만 담는다.
- 금지 항목은 실제로 지적된 표현만 추가한다. 잘못 걸리는 항목이 쌓이면 검사를 끄게 된다.
