# pack: _dev-prose — 개발 산문 공용 층

하네스 문서와 코드 주석과 결정 기록 같은 개발 산문에 공용 층 위로 겹쳐 적용한다.

## 원칙

- 실사용 개발 어휘를 쓴다. 영어 기술 용어를 한국어 순화어로 바꿔 부르지 않는다.
- 사물 주어에 사람 동사를 붙이지 않는다.
- 판정 질문은 하나다. 그 문장을 코드 리뷰나 이슈에 그대로 쓸 수 있는가.

## 교정 사전 (기본값)

| 피해야 할 말 | 바른 말 |
|---|---|
| 앞머리 | frontmatter, 접두어 |
| 방아쇠 | 트리거 |
| 구르다, 구르는 칸 | 스크롤, 스크롤되는 칸 |
| 걷다, 걷히다 (표시 제거) | 감추다, 표시되지 않다 |
| 세우다, 서다 (요소 배치) | 표시하다, 배치하다 |
| 들다 (값 보유) | 담다, 갖다 |
| 되살아나다 | 다시 표시되다 |
| 돌다 (실행) | 실행되다, 동작하다 |
| 열쇠 | 키 |
| 단추 | 버튼 |
| 손잡이 | 진입점, 버튼 |
| 덩이 (요소 묶음) | 블록, 박스, 묶음 |

## 결정론 검사

기계 검사용 금지 목록은 `packs/banned-words.json` 하나다. 훅이 모든 Write 와 Edit 에서 이 목록을 읽어 검사한다. 목록에는 오탐이 적은 형태만 담고, 동사 활용처럼 오탐이 많은 항목은 이 문서의 표로만 관리한다.
