# personal — 개인 데이터

개인화를 쓸 때만 채워지는 폴더입니다. **배포본에는 비어 있는 것이 정상입니다.**

여기 들어오는 것은 여러분이 직접 쓴 글과 거기서 측정한 수치입니다. 남과 공유하는 자료가 아니라서 저장소에도 올라가지 않습니다(`.gitignore` 처리).

| 경로 | 무엇 | 누가 만드나 |
|---|---|---|
| `corpus/<장르>/*.txt` | 직접 쓴 글. 1편 1파일 순수 텍스트 | 사람이 넣는다 |
| `manifest.md` | 편별 출처와 AI 사용 여부 판정과 용도 | 사람이 적는다 |
| `holdout.md` | 평가 전용으로 봉인한 글 목록 | `select-holdout.py` |
| `fingerprint/<장르>.json` | 측정된 지문 | `build-fingerprint.py` |
| `packs/<장르>.md` | 지문을 인용한 장르별 재작성 지침 | 에이전트가 지문을 보고 쓴다 |

## 지킬 것 둘

1. **AI 의 도움을 받아 쓴 글은 넣지 않습니다.** 섞이면 결국 AI 말투를 다시 배웁니다. 판정 근거는 `manifest.md` 에 남깁니다.
2. **`fingerprint/` 를 손으로 고치지 않습니다.** 수치는 측정 스크립트만 만듭니다. 사람이 적어 넣은 수치는 근거가 없습니다.

절차는 [../guides/personalize.md](../guides/personalize.md) 에 있습니다.
