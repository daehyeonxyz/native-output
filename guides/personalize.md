# 내 말투 학습

선택 단계입니다. 이 절차를 밟지 않아도 스킬은 `standards/` 의 기준만으로 완전하게 동작합니다.

여기서 하는 일은 하나입니다. 여러분이 직접 쓴 글을 측정해서, "자연스러운 한국어" 라는 목표를 "여러분이 쓴 것 같은 한국어" 로 바꿉니다.

## 필요한 것

파이썬과 형태소 분석기가 필요합니다.

```bash
pip install kiwipiepy
```

## 절차

Claude Code 에서 `/native-output intake` 라고 말하고 아래를 따르면 에이전트가 진행합니다. 무엇이 일어나는지 알고 싶을 때 이 문서를 봅니다.

### 1. 글을 모은다

예전에 써 둔 블로그 글, 과제, 일기, 발표 대본을 그대로 건넵니다. 붙여 넣어도 되고 파일로 줘도 됩니다. **장르당 5편 이상**이면 의미 있는 수치가 나옵니다.

한 가지만 지켜 주세요. **AI 의 도움을 받아 쓴 글은 건네지 않습니다.** 그런 글이 섞이면 결국 AI 말투를 다시 배웁니다.

### 2. 코퍼스에 넣는다

`personal/corpus/<장르>/` 에 1편 1파일 순수 텍스트로 들어가고, `personal/manifest.md` 에 한 행씩 기록됩니다.

```markdown
| id | 장르 | 출처 | 작성 시기 | AI 사용 | 용도(학습/평가) |
```

### 3. 장부를 점검한다

```bash
PYTHONIOENCODING=utf-8 python install/scripts/check-integrity.py
```

장부와 실물이 맞는지, 같은 글이 두 번 들어가지 않았는지 봅니다.

### 4. 평가용 글을 봉인한다

```bash
PYTHONIOENCODING=utf-8 python install/scripts/select-holdout.py
```

코퍼스의 약 14% 를 평가 전용으로 떼어 둡니다. 이 글들은 기준을 만드는 데 쓰지 않습니다. 나중에 "측정한 것이 처음 보는 내 글에도 맞는가" 를 확인할 때만 씁니다. 무작위가 아니라 결정론으로 고르므로 재실행해도 같은 글이 봉인됩니다.

### 5. 지문을 측정한다

```bash
PYTHONIOENCODING=utf-8 python install/scripts/build-fingerprint.py
```

`personal/fingerprint/<장르>.json` 이 만들어집니다. 담기는 것은 이렇습니다.

- 종결어미 분포와 화계 비율
- 문장 길이 중앙값
- 쉼표 밀도
- 실측 0회 표현 목록. 흔한 AI 상투어 가운데 여러분이 한 번도 쓴 적 없는 말입니다
- 실사용 기록이 있는 상투어. 이 말들은 금지에서 풀립니다

`fingerprint/` 는 재생성 전용입니다. 손으로 고치지 않습니다.

### 6. 장르 팩을 쓴다

에이전트가 지문을 읽고 `personal/packs/<장르>.md` 를 씁니다. 수치는 지문 인용만 적습니다.

```markdown
# pack: <장르> — <한 줄 설명>

수치 출처: `fingerprint/<장르>.json` (측정일, 편수). 손으로 고치지 말 것. 재측정만.

## 말투
- 기본 화계와 비율.
- 상위 종결어미와 문장 버릇.

## 리듬
- 문장 길이 중앙값 <n>자.
- 쉼표 중앙값 <n>개/문장.

## 절대 안 쓰는 표현 (지문 실측 0회)
- fingerprint 파일의 never_use_candidates 를 가리킨다.
- 예외: probes_found 에 잡힌 말은 실사용이므로 금지하지 않는다.
```

### 7. 복제 품질을 확인한다

```bash
PYTHONIOENCODING=utf-8 python install/scripts/eval-holdout.py
```

봉인해 둔 글이 측정 범위 안에 드는지 봅니다. 통과하면 지문이 처음 보는 내 글에도 맞는다는 뜻입니다. 이탈이 나오면 코퍼스에 남의 글이나 다른 장르가 섞였을 가능성을 먼저 의심합니다.

## 다 되면

"내 문체로 써 줘", "이 글 내 말투로 다듬어 줘" 라고 부탁하면 됩니다. 아직 학습하지 않은 장르를 부탁하면 에이전트가 그 사실을 밝히고, 가장 가까운 장르로 대용했다면 그 사실도 함께 알립니다.

지문을 실제 글에 적용할 때 반복해서 걸리는 자리는 [measuring.md](measuring.md) 에 있습니다.
