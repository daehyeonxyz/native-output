# 독립 검수 절차

공개될 글, 중요도가 높은 글, 원문 보존 수정을 마친 글은 처음 보는 눈으로 검수한다. 별도 에이전트나 새 대화에 이 문서를 그대로 전달한다. 그럴 수 없으면 이 문서의 항목으로 직접 검수하되, 내용 검수와 표현 검수를 따로 진행한다.

- 내용 검수는 의미가 보존되었는지만 확인한다.
- 표현 검수는 자연스러운 한국어인지만 확인한다.
- 두 검수를 모두 통과해야 최종 통과다.
- 검수자는 직접 고치지 않는다. 문제가 있는 위치와 이유를 지적한다.

## 내용 검수

원문과 수정본을 의미 단위로 비교한다.

하나라도 다르면 해당 수정을 되돌린다.

1. 고유명사: 인명, 지명, 제품명, 기관명이 한 글자도 다르지 않은가.
2. 수치와 단위: 숫자, 백분율, 연도, 금액이 같은가. "3배" 를 "세 배" 로 적는 표기 변경은 허용한다.
3. 날짜와 시간: 연월일과 기간이 같은가.
4. 직접 인용: 따옴표 안의 내용이 원문과 완전히 같은가.
5. 법률과 규정: 조항 번호와 본문이 그대로인가.
6. 수식: 수학과 통계 표기가 보존되었는가.

다음은 위반이 확인되면 되돌리거나 다시 쓴다.

7. 주장의 방향: 긍정이 부정으로, 단정이 추측으로 바뀌지 않았는가.
8. 인과관계: 원인과 결과가 뒤바뀌지 않았는가.
9. 행위자: 피동을 능동으로 바꾸면서 행위의 주체가 달라지지 않았는가.
10. 범위: "모든", "대부분", "일부" 의 범위가 유지되었는가.
11. 긍정과 부정: 이중 부정을 풀면서 뜻이 뒤집히지 않았는가.
12. 순서: 시간이나 중요도 순서를 담은 나열이 보존되었는가.
13. 누락과 추가: 원문의 정보를 지우거나 원문에 없는 정보를 넣지 않았는가.

검수할 때 다음을 참고한다.

- 의미가 달라졌을 가능성이 보이면 되돌리는 쪽으로 판단한다.
- "매우 중요하다" 같은 상투 표현의 삭제는 의미 훼손이 아니다.
- "필요하다" 를 "해야 한다" 로 바꾸면 의무의 정도가 달라지므로 확인한다.
- 문장을 합치거나 나눌 때 인과와 시간 순서가 달라지지 않았는지 확인한다.
- 정밀도가 중요한 글에서 "50%" 를 "절반" 으로 바꾸면 정밀도가 낮아진다고 지적한다.

## 표현 검수

수정본을 한국어 독자가 읽었을 때 자연스러운지 확인한다.

- 남은 문제: 공용 레이어와 금지 목록으로 다시 확인하고 남은 항목을 센다. 원문과 비교해 줄지 않았으면 수정이 효과가 없었다는 뜻이다.
- 과도한 수정: 다음 가운데 둘 이상이 확인되면 과도한 수정으로 지적한다.
  - 보고서가 에세이처럼 바뀌는 등 글 종류가 달라졌다.
  - 원문에 없던 비유가 들어왔다.
  - 격식 있는 원문이 구어체로 바뀌었다.
  - 문장이 전부 짧아지거나 전부 길어져 읽기 어렵다.
  - 원문의 핵심 어휘가 다른 말로 바뀌어 주제를 따라가기 어렵다.
- 읽기 확인: 조사와 어미가 자연스러운가. 문단 사이 논리가 이어지는가. 읽다가 걸리는 곳이 있는가.

## 판정

| 남은 문제 | 과도한 수정 | 판정 |
|---|---|---|
| 없음 | 없음 | 통과 |
| 경미함 | 없음 | 통과하되 남은 항목을 기록 |
| 있음 | 없음 | 지적된 범위만 다시 수정 |
| 무관 | 있음 | 해당 수정을 되돌린 뒤 다시 수정 |
| 있음 | 있음 | 중단하고 사람에게 보고 |

- 세 번 수정해도 통과하지 못하면 중단하고 사람의 검토를 요청한다.
- 검수 자체가 진행되지 못하면 그 사실을 산출물에 표시한다. 통과로 처리하지 않는다.
