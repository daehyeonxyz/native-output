# 한국어 출력 규칙

에이전트가 쓰는 모든 한국어에 적용하는 전역 규칙이다. 세션마다 자동 로드되고 항상 적용한다. 세부 기준은 native-output 스킬의 `standards/` 가 갖는다.

## 적용 범위

한글이 한 글자라도 들어가는 산출물 전부다. 문서와 보고서, 커밋 메시지와 PR 설명, 코드 주석, 화면 문구, 발표 자료, 사용자에게 보내는 대화 응답이 해당한다. 사용자가 스킬을 부르지 않아도 적용한다.

## 쓰기 전

목적과 독자를 먼저 정한다. 왜 쓰는가 → 어디에 실리고 누가 읽는가 → 메시지 → 내용 → 형식 → 문장의 순서다. 화계는 이 순서의 결과이지 출발점이 아니다. 고칠 글이 오면 손대기 전에 목적에 비춰 내용부터 판정한다.

## 쓸 때

- **문장**: 무생물 주어를 행위자로 만들지 않는다. "~을 갖는다" 와 이중 피동과 "~를 통해" 를 쓰지 않는다. 맥락으로 아는 주어는 생략하되 서술어가 가리키는 대상은 문장 안에서 확인되게 쓴다.
- **구성**: 결론이나 판단을 먼저 선언하고 근거를 뒤에 둔다. 반론과 유보는 끝에 몰지 말고 해당 주장 곁에서 처리한다. 개수를 예고했으면 한 문장 안에 전부 공급한다.
- **표현**: 한 글 안에서 화계를 섞지 않는다. em-dash 와 이모지를 쓰지 않는다. 비유와 의인화를 쓰지 않고 은유로 새 이름을 만들지 않는다.
- **장르**: 문장 길이와 쉼표 밀도는 장르마다 다르다. `standards/genres.md` 의 표를 기준으로 삼는다. 산문에서는 쉼표를 정상적으로 쓴다.
- **제목**: 산문 소제목은 그 절이 주장하는 것을 그대로 말한다. 슬라이드 제목과 화면 라벨은 반대로 가장 짧은 건조 명사구다.

## 판정

- 최종 판정은 그 문장이 자연스러운 한국어인가다. 금지 목록에 걸렸는가가 아니다.
- 상투어는 장르가 판정한다. "결론적으로" 는 보고서에서 정상이고 회고 글에서 AI 티다. 기계로 일괄 제거하지 않는다.
- 교정은 원문을 읽고 문장 단위로 다시 쓴다. 일괄 치환 스크립트를 쓰지 않는다.
- 수치를 지어내지 않는다. 목록에 없는 장르는 가장 가까운 장르로 대용하고 그 사실을 밝힌다.
- 목록에 없는 장르의 화계는 단정하지 않고 후보와 근거를 정리해 사용자에게 묻는다.
