# native-output

AI가 자연스러운 한국어로 쓰게 만드는 Claude Code 스킬.

## 무엇을 해결하나

AI에게 글을 맡기면 매끈해 보이지만 어딘가 어색합니다. 영어를 그대로 옮긴 듯한 문장 구조와 어느 글에나 나오는 표현이 섞이면서, 읽는 사람은 AI가 쓴 글임을 바로 알아챕니다.

native-output은 에이전트가 한국어를 쓸 때마다 번역투와 AI 티가 나는 표현, 영어식 글 구성을 걸러내서 처음부터 자연스러운 한국어로 쓰게 만듭니다. 걸러내는 기준이 `standards/` 폴더에 평문으로 전부 들어 있고, 설치하고 나면 따로 부르지 않아도 한국어 글을 쓰는 모든 작업에 자동으로 적용됩니다.

두 가지 방식으로 씁니다.

- **팀 표준으로.** `standards/` 를 회사 글쓰기 기준으로 고쳐 두면, 팀원 모두의 에이전트가 같은 기준으로 씁니다. 용어 표기와 금지 표현을 한곳에서 관리합니다.
- **개인 문체로.** 본인이 직접 쓴 글을 몇 편 넣으면 문장 길이와 말끝 같은 버릇까지 측정해서, "내 문체로 써 줘" 한마디로 내가 쓴 것처럼 읽히는 글을 받습니다. 선택 기능이고, 안 써도 위의 기준은 그대로 동작합니다.

## 빠른 시작

1. 이 폴더를 통째로 `~/.claude/skills/native-output/` 에 둡니다. 폴더 이름은 `native-output` 그대로여야 합니다.
2. Claude Code에서 `/native-output setup` 이라고 입력합니다.
3. 검사 강도를 물어보면 처음이라면 **알림만(`warn`)** 을 고릅니다.
4. Claude Code를 한 번 재시작합니다.

node만 있으면 됩니다. 파이썬은 개인 문체 학습을 할 때만 필요합니다. 자세한 절차와 문제 해결은 [guides/setup.md](guides/setup.md) 에 있습니다.

## 폴더 구조

폴더마다 역할이 하나씩입니다.

```text
native-output/
  README.md      ← 지금 읽는 문서
  SKILL.md         에이전트가 읽는 작업 지침. 사람이 읽을 필요는 없습니다

  standards/       글쓰기 기준. 팀이 함께 읽고 고치는 곳
  guides/          사람이 필요할 때 여는 절차 문서
  install/         설치되는 것들 (훅, 스크립트, 전역 규칙)
  personal/        개인 데이터. 기본은 비어 있고 공유하지 않습니다
```

| 폴더 | 무엇이 들었나 | 언제 여나 |
|---|---|---|
| [standards/](standards/) | 판단·문장·글·표현·장르의 다섯 층과, 개발 산문·화면 문구·발표 자료의 전용 층 | 기준이 궁금할 때. 팀 표준으로 고칠 때 |
| [guides/](guides/) | [설치](guides/setup.md), [내 말투 학습](guides/personalize.md), [독립 검수 절차](guides/review.md), [측정 규율](guides/measuring.md) | 그 작업을 할 때 |
| install/ | 훅 3종, 설치·측정 스크립트, 전역 규칙 파일 | setup이 알아서 씁니다 |
| [personal/](personal/) | 직접 쓴 글, 측정된 지문, 장르 팩 | 개인화를 쓸 때만 |

무엇이 왜 이 순서로 겹치는지는 [standards/README.md](standards/README.md) 에 있습니다.

## 팀 표준으로 쓰기

`standards/` 는 고쳐 쓰라고 있는 폴더입니다. 실제로 손댈 자리는 셋입니다.

1. `standards/style.md` 의 AI 상투 표현 목록 — 팀에서 실제로 반려된 표현을 넣고, 우리 분야에서 정상인 표현은 뺍니다.
2. `standards/dev-prose.md` 의 교정 사전 — 회사 용어집과 제품명 표기를 여기로 옮깁니다.
3. `standards/banned-words.json` — 기계가 막을 항목. 오탐이 적은 형태만 담습니다.

고친 폴더를 그대로 팀에 배포하면 모두가 같은 기준으로 씁니다. 금지 항목은 실제 반려가 관측될 때만 늘립니다. 있을 법한 표현을 미리 넣으면 오탐이 쌓이고, 오탐이 쌓이면 아무도 이 문을 열어 두지 않습니다.

## 평소 사용법

- 한국어 글을 쓰는 작업이면 자동으로 적용됩니다. 따로 할 일이 없습니다.
- 말투를 학습해 두었다면 "내 문체로 써 줘", "이 글 내 말투로 다듬어 줘" 라고 부탁합니다.
- 남의 글이나 기계가 만든 글을 다룰 때는 `NATIVE_OUTPUT_GATE=off` 를 붙여 실행해 검사를 끕니다.
- 지금 상태가 궁금하면 `/native-output status` 라고 입력합니다.

## 이 스킬이 하지 않는 것

- **에이전트의 대화 말투는 바꾸지 않습니다.** 목표는 산출물이지 채팅 말투가 아닙니다.
- **수치를 지어내지 않습니다.** 문장 길이나 화계 비율 같은 수치는 실제 글을 측정해야만 나옵니다. `standards/` 에 수치가 하나도 없는 이유입니다.
- **기계로 일괄 치환하지 않습니다.** 금지 목록에 걸렸는지가 아니라 그 문장이 자연스러운 한국어인지가 최종 판정입니다.
