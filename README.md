# native-output

AI가 자연스러운 한국어로 쓰게 만드는 글쓰기 스킬.

AI에게 글을 맡기면 매끈해 보이지만 어딘가 어색합니다. 영어를 그대로 옮긴 듯한 문장 구조와 어느 글에나 나오는 표현이 섞이면서, 읽는 사람은 AI가 쓴 글임을 바로 알아챕니다.

native-output은 에이전트가 한국어를 쓸 때마다 번역투와 AI 티가 나는 표현, 영어식 글 구성을 걸러내서 처음부터 자연스러운 한국어로 쓰게 만듭니다. 걸러내는 기준이 이 폴더에 전부 들어 있어서, 설치하고 나면 따로 부르지 않아도 한국어 글을 쓰는 모든 작업에 자동으로 적용됩니다.

여기에 개인화를 얹을 수 있습니다. 여러분이 직접 쓴 글을 몇 편 넣어 두면 문장 길이와 말끝 같은 버릇까지 학습해서, "내 문체로 써 줘" 한마디로 내가 쓴 것처럼 읽히는 글을 받습니다.

## 무엇을 걸러내나

기준은 층으로 쌓여 있고, 쓰는 글의 종류에 따라 필요한 층이 겹쳐 적용됩니다.

| 층 | 하는 일 |
|---|---|
| 판단 | 문장을 다듬기 전에 왜 쓰는지, 누가 읽는지, 무엇이 빠졌는지부터 정합니다 |
| 문장 | 무생물 주어, 이중 피동, "~을 갖는다" 같은 번역투를 거릅니다 |
| 글 구성 | 결론을 뒤로 미루는 영어식 구성과 반론 몰아두기를 거릅니다 |
| 표현 | 화계 섞임, em-dash, 이모지, "살펴보겠습니다" 계열을 거릅니다 |
| 장르 | 블로그와 에세이와 보고서와 필기가 각각 다른 구조를 갖습니다 |

여기에 세 가지 특수 장르가 더 있습니다. 개발 문서와 명세, 앱과 웹의 화면 문구, 발표 자료입니다. 산문 규칙을 그대로 옮기면 틀리는 자리라 따로 다룹니다.

## 시작하기

설치는 두 단계면 끝납니다.

1. 이 폴더를 통째로 Claude Code의 스킬 폴더에 복사합니다. 경로는 `~/.claude/skills/native-output/`입니다. 복사가 어려우면 Claude Code에게 "이 폴더를 스킬 폴더로 옮겨 줘"라고 부탁해도 됩니다.
2. Claude Code에서 `/native-output setup`이라고 입력합니다. 필요한 프로그램 확인부터 자동 검사 설정까지 에이전트가 알아서 진행하고, 끝나면 Claude Code를 한 번 재시작합니다.

여기까지만 하면 자연스러운 한국어 출력은 바로 적용됩니다. node만 있으면 되고, 파이썬은 아래의 말투 학습을 할 때만 필요합니다.

### 검사 강도 고르기

setup 중에 자동 검사를 얼마나 세게 걸지 물어봅니다. 셋 중에 고르면 됩니다.

- **알림만**: 걸리는 표현이 있으면 알려 주기만 하고 막지는 않습니다. 처음 써 본다면 이쪽을 권합니다.
- **차단**: 규칙에 어긋나면 편집 자체를 거부합니다. 기준을 확실히 강제하고 싶을 때 고릅니다.
- **끄기**: 자동 검사 없이 규칙 문서만 얹습니다.

나중에 마음이 바뀌면 `node scripts/setup-hooks.js --level=warn` 처럼 다시 실행해 강도만 바꿀 수 있습니다.

## 내 말투 학습

개인화를 원할 때 한 번 해 두는 선택 단계입니다. 이 단계는 파이썬과 형태소 분석기(`pip install kiwipiepy`)가 필요합니다.

`/native-output intake`라고 말하고 예전에 써 둔 블로그 글이나 과제, 일기 같은 글을 그대로 붙여 넣거나 파일로 건넵니다. 장르당 5편 이상 모이면 "지문을 측정하고 장르 팩을 만들어 줘"라고 부탁합니다. 건넨 글은 이 폴더 안에만 저장되고, 글을 더 넣을수록 말투가 정확해집니다.

한 가지만 지켜 주세요. AI의 도움을 받아 쓴 글은 건네지 않습니다. 그런 글이 섞이면 결국 AI 말투를 다시 배우게 되기 때문입니다.

## 평소 사용법

- 한국어 글을 쓰는 작업이면 자동으로 적용됩니다. 따로 할 일이 없습니다.
- 말투를 학습해 두었다면 "내 문체로 써 줘", "이 글 내 말투로 다듬어 줘"라고 부탁합니다.
- 내 문체를 부탁했는데 아직 학습하지 않은 장르라면, 에이전트가 그 사실을 밝히고 필요하면 예시 글을 받아 맞춥니다.
- 남의 글이나 기계가 만든 글을 다룰 때는 검사를 잠시 끕니다. `NATIVE_OUTPUT_GATE=off` 를 붙여 실행하면 됩니다.

에이전트가 따르는 자세한 규칙과 폴더 구조는 `SKILL.md`에 있습니다.
